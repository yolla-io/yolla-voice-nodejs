# @yolla-io/yolla-voice-nodejs

Node.js server SDK for the Yolla Voice Reseller API.

Status: pre-release (0.1.0). The API may change before 1.0.

## Install

```sh
npm install @yolla-io/yolla-voice-nodejs
```

Requires Node.js 20.19 or newer. ESM only, no runtime dependencies.

## Documentation

Documentation: https://github.com/yolla-io/yolla-voice-nodejs#readme (full usage guide coming with the first release).
